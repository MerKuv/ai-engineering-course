# 📌 Внутренний регламент предприятия «ПромТех»:  
**«Регламент реагирования на инциденты на технологических установках»**

## ⚪ Шапка документа

```
# Название документа: Регламент реагирования на инциденты на технологических установках  
# Документ: РГЛ-РИ-007  
# Версия: 3.1  
# Утверждён: Директором по производству  
# Дата утверждения: 10.09.2023 г.  
# Дата вступления в силу: 15.10.2023 г.  
# Область действия: Производственные цеха №1–№3, участок подготовки сырья, участок переработки нефти  
# Периодичность пересмотра: раз в три года  
```

## 🔗 Содержание документа

### 1. Назначение и область применения  
Настоящий документ устанавливает порядок действий персонала производственных подразделений при возникновении инцидентов на технологических установках предприятия «ПромТех».  

### 2. Термины и определения  
Инцидент — событие, приводящее к отклонению от нормального режима работы установки и угрожающее её безопасной эксплуатации.  

### 3. Порядок выявления инцидента  
#### 3.1 Пороговые значения срабатывания сигнализации  
При достижении следующих значений немедленно инициируется процедура реагирования:  
- Температура перегонки выше +350 °C (установка УПП-101);  
- Давление свыше 2,5 МПа (установка УПТ-202).  

#### 3.2 Ответственность за выявление инцидента  
Ответственным лицом является оператор технологического процесса, зафиксировавший отклонение параметров.  

### 4. Действия персонала при инциденте  
#### 4.1 Первичные меры безопасности  
Оператор обязан незамедлительно отключить установку от общего трубопровода, перекрыть задвижки и подать сигнал тревоги.  

#### 4.2 Состав комиссии по расследованию инцидента  
Комиссия формируется из начальника смены, инженера по эксплуатации и технолога установки.  

### 5. Оформление акта расследования инцидента  
Акт составляется комиссией в течение трёх рабочих дней после происшествия и содержит следующие обязательные реквизиты:  
- Дата и время инцидента;  
- Описание произошедшего события;  
- Причина возникновения инцидента;  
- Предложения по предотвращению повторения ситуации.  

Форма акта утверждена формой РГЛ-Ф-08.  

### 6. Планирование мероприятий по устранению последствий инцидента  
На основании акта комиссия разрабатывает план мероприятий по восстановлению нормальной работы установки и предотвращения аналогичных ситуаций в будущем.  

### 7. Информирование руководства и служб предприятия  
После устранения инцидента руководитель производственного подразделения докладывает руководству предприятия о проведённых мероприятиях и принятых мерах.  

### 8. Исключения и особые случаи  
- Если инцидент произошёл на оборудовании, не указанном в данном регламенте, требования к действиям персонала определяются отдельно регламентом РГЛ-ХХ-002.  
- В случае отсутствия данных о типе оборудования решение принимает инженер по эксплуатации самостоятельно.
